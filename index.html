GAMEBUINO Classic — playable in your browser

Every Gamebuino Classic game and tool whose source could still be found, compiled from that source and running here on Myndale’s Simbuino HTML5 emulator. The console was an ATmega328 handheld with an 84×48 Nokia 5110 screen, and its community wiki — along with most of what it linked to — is long gone from the live web.

105 games and 14 tools. Nothing here is my own work: every entry is someone else’s game, credited below with its own licence.

Controls

Every game runs in the same emulator, with the same keys:

Arrows or ESDFD-pad X or KA button Z or LB button C or RC button

Most games open on a title screen and start with A. On a phone, on-screen buttons appear instead.

How this was built

Each entry was compiled from the archived source with the Arduino IDE 1.8.19 AVR toolchain, targeting the ATmega328 at 16 MHz, against Gamebuino Classic library 0.5.2. A number of sketches needed small fixes to build on a modern avr-gcc — mostly PROGMEM data that now has to be const, the removed prog_uchar type, and pre-2014 library API calls. Those fixes were applied to build-time copies; the source archive itself is untouched. A few entries ship only as a prebuilt .hex from their own author and are marked as such. Screenshots were captured by running each build in the emulator under headless Chrome.
